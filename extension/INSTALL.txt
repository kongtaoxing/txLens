Chrome / Edge: open Extensions → Developer mode → Load unpacked → select this folder.
Chrome / Edge：扩展程序管理 → 开发者模式 → 加载已解压的扩展程序 → 选择此文件夹。
Pin TxLens, then reload your dApp. 固定 TxLens，然后刷新网站。

Local checks do not need an account, API key or backend.
本地检查无需账户、API Key 或后端。
Hosted builds connect to their production service. Local builds use http://localhost:5173. You can change the HTTPS backend URL in extension settings.
网站构建的安装包连接正式服务；本地构建默认连接 http://localhost:5173。可在插件设置中修改 HTTPS 服务地址。
Never put an AI API key in the extension. Do not enter a wallet seed phrase anywhere in TxLens.
不要把 AI 密钥写入插件，不要向 TxLens 提供钱包助记词。

Coverage: EIP-1193 request + EIP-6963 injected EVM wallets. Legacy send/sendAsync, locked global entries, pre-cached original methods, non-EVM wallets and direct RPC broadcasts are not intercepted. Frozen wallet objects are supported through configurable entries and EIP-6963. This is a best-effort review assistant, not a security boundary against a malicious page. A wallet can always receive requests through paths outside the extension.
覆盖：通过 EIP-1193 request 与 EIP-6963 注入的 EVM 钱包。无法拦截旧 send/sendAsync、锁定的钱包入口、提前缓存的原始方法、非 EVM 钱包及直接广播的请求。冻结的钱包对象可通过可替换入口或 EIP-6963 接入。插件是审阅助手，不是阻止恶意网页绕过的安全边界。
Transaction behavior is not simulated. Check your wallet's final preview. Unknown fields do not imply safety.
未模拟交易执行，请核对钱包最终预览。未识别不代表安全。

Privacy: settings and temporary requests stay in browser storage. Review requests are removed on completion/cancellation/timeout. AI is optional: clicking Explain sends decoded request facts to your configured TxLens backend and its configured model provider. No private keys, automatic signing, transaction fees or review-history database.
隐私：设置和待处理请求保存在浏览器中；请求在完成、取消或超时后删除。点击 AI 解释才会把可读请求信息发给你配置的 TxLens 后端及其模型服务。不收私钥，不自动签名，不收交易费用，不建立审阅历史数据库。

Updating / 更新旧版：
If TxLens is already installed, replace the files in its loaded folder and click Reload in the browser's Extensions page. Then reload the actual dApp tab, not just localhost.
若已安装，请更新原来加载的文件夹，在扩展管理页点击 TxLens 的“重新加载”，然后刷新实际发起授权的网站，不是只刷新 localhost。
Open TxLens on the dApp to check each wallet entry. Partial or missing attachment can miss requests. Entry attachment is not proof of a completed transaction test. The check does not request accounts, signatures or transactions.
在授权网站上打开 TxLens，查看各钱包入口状态。部分入口未接入或未接入时，可能无法自动审阅。入口接入不代表已完成实际交易验证。检查本身不会请求账户、签名或交易。
The localhost page is an interactive preview; simply opening it does not install the extension.
localhost 网页是交互预览，只打开网页并不会安装插件。

从 v0.2.3 或更早版本升级：v0.2.4 开始固定插件 ID。浏览器可能将其识别为新的安装，请确认 AI 服务地址和暂停设置；之后换目录解压不会再改变 ID。
Upgrading from v0.2.3 or earlier: v0.2.4 pins the unpacked extension ID. The browser may treat the first upgrade as a new installation; check your AI service address and pause preferences. Later folder changes retain the ID.

界面与 AI 回复跟随浏览器语言，当前支持中文和英语，其他语言使用英语。
Interface and AI replies follow browser language. Chinese and English are supported; other languages use English.
